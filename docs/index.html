mterm>_
Terminal lokal untuk Android — core Rust + PTY, UI Compose. Open source.

Apa itu mterm?

Emulator terminal yang berjalan lokal di perangkat Android: seluruh pipeline disusun dari libc crate (Rust) untuk PTY/shell, engine terminal (grid, scrollback, escape-sequence, SGR mouse), dan JNI bridge. Tidak ada server eksternal — tiap baris yang muncul adalah kerja Rust core di device.

Fitur

  • Beberapa tab terminal, masing-masing sesi PTY + shell tersendiri
  • Sidebar: cwd, status git, penjelajah file dengan preview read-only
  • Scrollback, seleksi, mode mouse SGR untuk TUI (vim/tuistyle apps)
  • Foreground service + notifikasi persistent; otomatis save/restore sesi
  • Theme: ikuti sistem / terang / gelap + warna aksen + ukuran font
  • Onboarding first-launch
  • Localization skeleton (id + en), dark/light mengikuti preferensi

Teknologi & struktur

mterm/
├─ crates/
│  ├─ jni/        # JNI bridge (export Java_*), spawn PTY thread
│  ├─ core/       # engine terminal: grid, scrollback, SGR mouse, save-state
│  └─ mterm-cli/  # tooling host (node install, dll.)
├─ app/
│  └─ app/        # Android app (Kotlin + Compose) — MainActivity, tabs, sidebar,
│                 # settings, onboarding, foreground service (TermService)
└─ scripts/       # adb-wireless, build-android (--ci / --pull / --install)

Kompilasi: Rust cargo → cargo ndk → shared lib arm64-v8a di jniLibs → Gradle assembleDebug. CI (GitHub Actions) menjalankan fmt, clippy -D warnings, cargo test (114 test hijau), lalu build APK.

Build & instal lokal

# build + instal lewat CI artifact ke device (lewat ADB wireless)
./scripts/build-android.sh --pull

# pasang APK yang sudah di-pull
./scripts/build-android.sh --install app/app/build/outputs/apk/debug/app-debug.apk

# koneksi ADB wireless (isi port baru dari HP bila kadaluarsa)
./scripts/adb-wireless.sh connect   # atau: save/pair/show

Arsitektur inti

Terminal dibangun dengan model reader/engine + aplikasi TUI:

shell (PTY master) ──bytes──▶ Rust feed ──▶ engine ──▶ grid + events
           ▲                                                    │
           └──────── Kotlin input()/write() ◀─ chrome gestures ◀─┘
  • Feed dari stdout PTY masuk ke engine — aplikasi TUI yang menulis ESC[?1006h akan otomatis mengaktifkan mode mouse SGR.
  • Event ke keyboard: session.input() menulis ke PTY stdin (shell); session.write() mengirim langsung ke engine (alur aplikasi TUI).
  • State terminal bisa diseriakan ke JSON (to_json/from_json) untuk auto-save/restore dan parsing test.
